## Vivado Analysis

The RTL design was analyzed using Xilinx Vivado.

The following design analysis results are included in the repository:

### RTL Schematic

The RTL schematic generated by Vivado is included to show the RTL-level structure of the traffic controller.

### Synthesis Schematic

The synthesized design schematic generated by Vivado is included to show the synthesized hardware structure.

### Power Analysis

The Vivado power analysis results are included to document the estimated power consumption of the design.

### Device and Package

The target FPGA device and package information used for the design analysis are documented in the repository.
